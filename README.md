# MelodyBank - Backend Foundation Milestone

## Project Overview
MelodyBank is a MIDI marketplace platform where users can browse, upload, save, and manage MIDI sequences. The goal of this milestone is to establish the backend foundation of the system using Spring Boot, organized models, repositories, services, and basic controller structure.

## System Purpose
The application is designed to support music creators by allowing them to manage MIDI content in a structured system. Future milestones will expand this foundation with database persistence, frontend integration, authentication, and external API support.
